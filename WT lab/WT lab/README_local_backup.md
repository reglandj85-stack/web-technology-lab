# Web Technology Lab

This repository contains the laboratory experiments for the **Web Technology** course.

## Experiments

The experiments are organized separately from **Experiment 1 to Experiment 10**.

Each experiment contains:

- **PG** – Program/source code
- **OP** – Output/result screenshots or files
